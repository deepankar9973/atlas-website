# Atlas Landing Page Copy Options

This directory contains alternative landing page copy approaches for the Atlas website.

## Available Options

### 1. Paradigm-Inspired Option
**File**: `paradigm-inspired-option.md`

A premium, enterprise-focused approach inspired by Paradigm's elegant design philosophy:

**Key Characteristics**:
- Clean, sophisticated typography with serif headlines
- Minimal, benefit-focused messaging
- Interactive preview and template system
- Visual-first product demonstrations
- Darker, more dramatic aesthetic
- Professional tone for enterprise buyers

**Best for**:
- Targeting VPs of Product, design leaders, and enterprise decision-makers
- Well-funded startups that value craft and sophistication
- Audiences familiar with modern SaaS tools

**Tone**: Elegant, measured, confident without being aggressive

---

## Comparison Guide

| Aspect | Paradigm-Inspired |
|--------|------------------|
| **Visual Style** | Dark palette, serif headlines, high contrast |
| **Messaging** | Benefit-implicit, shows vs tells |
| **Structure** | Interactive preview first, template-based |
| **Paragraph Length** | 1-2 sentences max |
| **Target Audience** | Enterprise, VPs, design leaders |
| **Engagement** | "Try now" templates, progressive disclosure |
| **Social Proof** | Logo carousel, executive testimonials |

## Next Steps

1. **Review**: Compare the different approaches
2. **Choose**: Select the option that best fits your brand positioning
3. **Customize**: Adapt the chosen copy with specific company names, metrics, and testimonials
4. **Design**: Work with designers to implement the visual treatment recommendations
5. **Test**: A/B test different sections to optimize conversion

## Notes

- All copy options are living documents and can be mixed/matched
- Consider your primary audience when choosing an approach
- The "Paradigm-Inspired" option assumes more sophisticated users
- Visual treatment is as important as copy for the Paradigm approach
